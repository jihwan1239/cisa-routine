# CISA 루틴

직장인을 위한 CISA 하루 5분 학습 앱입니다. GitHub Pages로 배포합니다.

## 배포
1. 이 폴더의 파일을 저장소 루트에 그대로 올립니다. `.github` 폴더도 포함해야 알림이 작동합니다.
2. Settings > Pages에서 `main` 브랜치, `/ (root)`를 선택합니다.
3. 휴대폰에서 주소를 열고 홈 화면에 추가합니다.

교재 PDF, 백업 JSON, API 키는 저장소에 올리지 마세요.

## 앱을 닫아도 오는 알림 설정
앱 설정 탭의 안내를 따라 아래 Secrets를 등록합니다 (Settings > Secrets and variables > Actions).

| 이름 | 값 |
|---|---|
| VAPID_PUBLIC_KEY | 앱에서 만든 공개키 |
| VAPID_PRIVATE_KEY | 앱에서 만든 개인키 |
| VAPID_SUBJECT | mailto:본인이메일 |
| PUSH_SUBSCRIPTION | 기기에서 알림 켜기 후 나온 값 (여러 기기면 [값1, 값2]) |

- 알림 시각: `.github/workflows/streak-reminder.yml`의 cron (UTC). 기본은 한국 시간 21시입니다.
- GitHub 예약 실행은 몇 분에서 수십 분 늦을 수 있습니다.
- 저장소에 60일 동안 변경이 없으면 GitHub가 예약 실행을 멈춥니다. 멈추면 Actions 탭에서 다시 켜세요.
- 아이폰은 iOS 16.4 이상에서 홈 화면에 추가한 앱으로 열어야 알림을 받을 수 있습니다.

## 파일
- `index.html` 앱 본체
- `bank-d1.js` ~ `bank-d5.js` 도메인별 연습 문제 100개씩 (공식 출제 범위 기반 자체 작성, 기출이나 덤프 아님)
- `bank-n1.js` ~ `bank-n5.js`, `bank-n4b.js` 정리 노트의 개념을 바탕으로 새로 쓴 추가 문제 175개 + 업로드 PDF 한글 문제 1,321개
- `bank-learn.js` 도메인별 6개씩 구성한 기본 이론 30개와 3지선다 빈칸 231개
- `sw.js` 오프라인 캐시와 알림 처리
- `push/send.mjs` 알림 발송 스크립트

## 학습 자료(PDF)
노트나 교재 PDF는 저장소에 넣지 말고 앱의 자료 탭에서 올리세요. 글자만 추출해 그 기기의 브라우저에만 저장됩니다. 읽기 화면에서 쪽 이동과 검색을 쓸 수 있습니다.

## 앱 업데이트 후 새 홈 화면 아이콘(북마크) 추가

### 같은 GitHub Pages 주소를 계속 쓰는 경우

1. 저장소의 기존 파일을 이 ZIP의 파일로 덮어씁니다. 새 파일 `bank-pdf-ko.js`, `bank-learn.js`와 `.nojekyll`도 반드시 올립니다.
2. GitHub Pages의 주소는 바꾸지 않습니다. 같은 주소라면 기존 브라우저 학습 기록(localStorage)과 업로드 자료(IndexedDB)가 유지됩니다.
3. 아이폰에서 Safari로 배포 주소를 온라인 상태에서 한 번 연 뒤 새로고침합니다. 앱의 문제 수가 **1,996개**인지 확인합니다.
4. 기존 홈 화면 아이콘을 그대로 사용할 수 있습니다. 아이콘을 새로 만들고 싶으면 기존 아이콘을 삭제한 뒤 Safari의 공유 > 홈 화면에 추가를 실행합니다.
5. 기존 아이콘 삭제만으로 브라우저 데이터가 지워지는 것은 아니지만, 작업 전 앱 설정에서 백업을 내려받는 것을 권장합니다.

### 저장소 이름·계정·도메인·Pages 경로가 바뀌는 경우

주소가 바뀌면 브라우저는 별도 앱으로 취급하므로 기존 기록과 설정이 자동으로 따라오지 않습니다.

1. 기존 앱 설정에서 **백업 내려받기**를 합니다. 백업에는 API 키, PDF 원문, 푸시 구독이 포함되지 않습니다.
2. 새 주소를 Safari에서 온라인으로 열고 **홈 화면에 추가**합니다.
3. 새 앱 설정에서 백업을 불러옵니다.
4. 필요하면 OpenAI API 키와 모델 이름을 다시 입력합니다.
5. 아래 알림 절차에 따라 새 주소에서 새 구독을 발급합니다.
6. 자료 탭에 올렸던 PDF는 새 주소에서 다시 올립니다. 문제은행에 포함된 1,321개 한글 문제는 `bank-pdf-ko.js`에 들어 있으므로 PDF를 다시 올리지 않아도 풀 수 있습니다.

### 푸시 알림을 계속 받기 위한 설정

새 홈 화면 앱이나 새 주소는 별도의 푸시 구독을 만들 수 있습니다. VAPID 키 쌍은 기존 것을 유지하세요.

1. GitHub 저장소의 `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` Secrets는 그대로 둡니다. 새 키를 만들면 기존 기기 구독이 동작하지 않게 됩니다.
2. 새 앱의 설정 > 연속 기록 알림에서 **이미 사용하는 VAPID 공개키**에 기존 `VAPID_PUBLIC_KEY`를 붙여넣고 적용합니다.
3. **이 기기 알림 켜기**를 누르고 새 `PUSH_SUBSCRIPTION` 값을 복사합니다.
4. 한 기기만 쓸 경우 GitHub Secret `PUSH_SUBSCRIPTION`을 새 값으로 교체합니다.
5. 기존 앱과 새 앱 모두 알림을 받을 경우 두 구독 객체를 JSON 배열로 등록합니다. 예: `[기존구독객체, 새구독객체]`. 문자열 따옴표로 감싸지 않습니다.
6. GitHub Actions > `streak-reminder` > Run workflow로 시험합니다. iPhone은 iOS 16.4 이상이며 홈 화면 아이콘으로 실행한 앱에서 알림을 허용해야 합니다.
7. 알림 시각을 바꾸려면 앱의 `알림 시각`과 `.github/workflows/streak-reminder.yml`의 cron을 함께 바꿉니다. GitHub cron은 UTC이므로 한국 시각에서 9시간을 뺍니다.
8. 공개 저장소에서 60일 동안 활동이 없으면 예약 workflow가 자동 비활성화될 수 있습니다. Actions에서 다시 활성화하거나 cron을 수정해 재활성화합니다.

### 홈 화면 이름·아이콘·시작 화면을 바꾸는 파일

| 변경 항목 | 파일 | 현재 값/주의사항 |
|---|---|---|
| 브라우저 제목 | `index.html`의 `<title>` | CISA 루틴 |
| iPhone 홈 화면 이름 | `index.html`의 `apple-mobile-web-app-title` | CISA 루틴 |
| 설치 앱 이름 | `manifest.webmanifest`의 `name`, `short_name` | CISA 루틴 |
| 홈 화면 아이콘 | `icon-192.png`, `icon-512.png` | 같은 파일명으로 교체 후 캐시 버전도 변경 |
| 시작 주소와 범위 | `manifest.webmanifest`의 `start_url`, `scope` | 저장소 하위 경로 배포를 위해 `./` 유지 |
| 상태바/테마 색 | `index.html`과 manifest의 `theme-color` | `#16233A` |
| 오프라인 파일 | `sw.js`의 `ASSETS` | 파일을 추가하면 목록에 포함 |
| 캐시 새 버전 | `sw.js`의 `CACHE` | 큰 업데이트마다 끝의 버전명을 변경 |
| 알림 아이콘 | `sw.js`의 `icon`, `badge` | 현재 `icon-192.png` |

같은 앱을 업데이트할 때 manifest의 별도 `id`를 새로 만들지 않았습니다. 기존 설치가 `start_url`을 앱 식별값으로 사용하므로 같은 주소에서 이어지는 업데이트에 적합합니다. 별개 앱으로 동시에 설치하려면 별도 GitHub Pages 경로와 별도 manifest를 사용하세요.

## 업로드 PDF 문제 반영

- 한글 본문과 추가 문제 1,339개를 확인했고, 보기·정답 구조가 분명한 1,321개를 `bank-pdf-ko.js`에 넣었습니다.
- 문제 풀기에서 출처를 **업로드 PDF 한글 문제**로 선택할 수 있습니다.
- 각 문제에 PDF 쪽수, 원문 문제번호, 원문 보기 라벨을 표시합니다.
- 원문에 2지선다와 5~8개 보기 문항이 있어 앱이 최대 8개 보기를 표시하도록 확장했습니다.
- 18개는 정답 표기나 보기 라벨이 불명확해 자동 채점에서 제외했습니다. 자세한 목록은 `PDF-반영결과.md`에 있습니다.
- PDF의 번역·정답·해설은 원문 그대로 옮긴 것으로, 공식 문제 또는 독립 검증된 답안이라는 의미는 아닙니다.

## 이론과 빈칸 학습

- 하단의 **카드** 탭을 **학습** 탭으로 바꿨습니다.
- 기본 이론은 전체 30개이며 5개 도메인에 6개씩 들어 있습니다.
- 각 단원은 핵심 용어와 설명을 먼저 읽고, 보기 3개 중 빈칸의 답을 고르는 방식입니다.
- 기본 빈칸은 전체 231개입니다. 이론 읽기를 완료한 단원의 빈칸만 복습에 나옵니다.
- 틀린 빈칸은 다음 날 다시 나오고, 맞힌 빈칸은 1일, 3일, 7일, 14일, 30일 순으로 간격이 늘어납니다.
- 같은 빈칸은 같은 날 다시 나오지 않습니다.
- 이론 읽기 시간과 빈칸 풀이가 연속 학습 기록에 반영됩니다.
- 오늘 화면의 **오늘의 이론 읽기**는 시험 비중이 크고 현재 정답률이 낮은 도메인을 고려해 아직 읽지 않은 단원을 고릅니다.
- 기존 플래시카드는 학습 탭 아래의 **직접 만든 카드**에서 계속 사용할 수 있습니다.
- 자료 탭의 AI 만들기에서 **이론 정리와 빈칸**을 선택할 수 있습니다. 선택한 PDF 글자가 OpenAI로 전송되므로 개인적이거나 민감한 자료는 사용하지 마세요.

## 같은 날 문제 중복 방지

- 일반 문제, 복습 문제와 모의고사는 오늘 이미 푼 문제를 해당 날짜의 다음 세션에서 제외합니다.
- 선택한 출처나 도메인의 남은 문제를 모두 풀면 같은 문제를 다시 내지 않고 남은 문제가 없다고 안내합니다.
- 학습 결과 화면에서 사용자가 직접 누르는 **오답 다시 풀기**는 의도적인 재학습이므로 직전 세션의 오답만 다시 출제합니다.
- 기존 기록에는 과거 풀이 날짜가 저장되어 있지 않으므로 업데이트 당일 이전 풀이까지 소급해 중복을 판별하지는 않습니다. 업데이트 이후 풀이부터 적용됩니다.
